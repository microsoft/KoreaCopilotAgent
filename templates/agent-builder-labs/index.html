Hands-on Lab Series · Agent Builder

코딩 없이 만드는
나만의 에이전트
한 번에 하나씩

Copilot Chat의 Agent Builder만 있으면 됩니다. 도구를 새로 깔 필요도, 코드를 쓸 필요도 없습니다. 아래 실습을 위에서부터 하나씩 따라 하세요. 각 실습은 10분 안팎이면 끝나고, 마칠 때마다 팀에 바로 공유할 수 있는 에이전트가 하나씩 남습니다.

Microsoft Korea · Hands-on Lab Series · 실습 3개 · 난이도 초급~중급
실습 목록

순서대로 하나씩 따라 하세요

순서를 지키지 않아도 됩니다. 다만 1번부터 하면 Agent Builder 화면에 먼저 익숙해집니다.

01

FAQ 에이전트 만들기

사내 문의를 대신 받아 주는 Copilot Help Buddy를 만듭니다. 안내 문구를 쓰고 공개 웹사이트를 지식 소스로 붙이면, 같은 질문에 늘 같은 기준으로 답하는 에이전트가 됩니다. 지식 소스를 연결하는 방법을 익힙니다.

공개 10~15분 초급 지식 소스 연결
02

Devil's Advocate 에이전트 만들기

내 계획에 일부러 반대편에 서는 에이전트를 만듭니다. Copilot은 대체로 사용자 편을 들지만, 이 에이전트는 가장 강한 반대 논거를 찾고 실패하는 경로를 그려 줍니다. 지식 소스 없이 안내만으로 성격을 바꾸는 방법을 익힙니다.

공개 10분 초급 안내만으로 제작
03

심의위원회 에이전트 만들기

위원장, 재무, 기술, 시장, 반론. 보는 기준이 다른 위원 다섯 명이 같은 안건을 놓고 4라운드로 다투게 만듭니다. 투자 심의나 임원 보고 전 자체 점검처럼 큰 결정을 앞두고 반대 의견을 미리 듣는 자리로 씁니다. 여러 역할을 한 에이전트에 담는 방법을 익힙니다.

공개 15분 중급 멀티 페르소나
04

준비 중 아이디어 남기기
개요

Agent Builder란?

Copilot Chat 안에서 도구를 새로 깔지 않고, 한국어 안내만으로 나만의 에이전트를 만드는 기능입니다.

💬

Copilot Chat 안에서 제작

웹 브라우저나 M365 Copilot 앱에서 바로 만듭니다. 설치하거나 환경을 따로 준비할 일이 없습니다.

📝

안내만으로 동작

"어떻게 답해야 하는지"를 한국어로 적으면 됩니다. 답변 규칙과 톤, 출력 형식을 그 자리에서 정합니다.

🚀

만들고 바로 공유

완성한 에이전트는 링크로 동료에게 넘길 수 있습니다. 받은 사람은 자기 Copilot에서 그대로 씁니다.

Copilot Studio와는 무엇이 다른가요?
Agent Builder는 안내와 공개 웹 지식만으로 빠르게 만드는 도구입니다. SharePoint나 Dataverse 연동, Power Automate 흐름, 사용자 지정 커넥터가 필요하면 Copilot Studio로 넘어가세요. 이 사이트의 다른 템플릿에서 Copilot Studio 예제를 볼 수 있습니다.
준비물

시작하기 전에 확인할 것

세 가지만 갖추면 바로 시작할 수 있습니다.

  • Microsoft 365 Copilot 계정
    회사 계정으로 Copilot Chat에 로그인할 수 있으면 됩니다.
  • Agent Builder 사용 권한
    조직의 라이선스와 관리자 정책에 따라 메뉴가 보이지 않을 수 있습니다. 화면에 에이전트 만들기 항목이 없으면 IT 담당자에게 문의하세요.
  • 웹 브라우저
    Edge나 Chrome이면 충분합니다. M365 Copilot 데스크톱 앱에서도 같은 화면이 나옵니다.
실습 중 화면이 안내와 다르다면?
Agent Builder는 자주 바뀝니다. 버튼 이름이나 위치가 조금 달라도 흐름은 같습니다. 만들기, 안내 입력, 지식 연결, 테스트 순서만 기억하면 됩니다.
